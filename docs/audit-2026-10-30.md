# Interlude main audit (2026-10-30)

Audit of `main` at 39d48a1 using the swiftui-pro, swift-concurrency and macos-spm-app-packaging skills. The fixes go on the `audit-fixes` branch (worktree `/Users/hari/projects/Interlude-audit`). This is a static read: nothing was run. Items marked **confirmed** were re-checked in the code.

Items are numbered and ranked quickest to longest within each group.

## Bugs

1. **World Clock "Tomorrow/Yesterday" wrong at month or year end** (confirmed). `Widgets.swift:509` compares day, month and year separately. For example, there = Nov 30 and here = Dec 1 shows "Tomorrow". Fix: compare the dates with `Calendar.compare(_:to:toGranularity: .day)`, or compare `(year, month, day)` as tuples.
2. **A fast re-show after Esc leaves a paused wallpaper and no music** (confirmed). `OverlayController.swift:101-109`: hide() runs `aerial.pause()` and `nowPlaying.stop()` 650 ms later, inside a Task that is never cancelled. Fix: store the Task and cancel it in show().
3. **A failed reminder tick-off still disappears from the card.** `Widgets.swift:225-227` uses `try? store.save`. The reminder stays open and comes back on the next refresh. Fix: use do/catch and keep the item when the save fails.
4. **Layout editor and overlay can use different screens.** The editor uses `NSScreen.main` (`Layout.swift:381`, `OverlayView.swift:62`, `Onboarding.swift:187`, `CardRenderer.swift:160`), but the overlay opens on `StartConditions.screen`. If those screens have different column counts, saved edits never show. Fix: use `StartConditions.screen` everywhere.
5. **Duplicate calendar events break the event list.** `OverlayView.swift:652,675` uses the event as its ForEach id. The same meeting on two calendars gives duplicate ids. Fix: give `Event` a real id (eventIdentifier).
6. **The music settings preview and the "Allow…" row go stale.** `Settings.swift:489-512` reads nowPlaying without observing it, so the pane doesn't update when a song or permission changes. Fix: use `@ObservedObject` and re-check on didBecomeActive.
7. **Aerial video failure gives a black screen forever.** `Aerials.swift:123-217` never checks the AVPlayerItem status, so a stream that fails offline is never replaced. Fix: observe `.failed` and load the next video.
8. **The welcome window's starter layout overwrites the custom layout without asking** (`Onboarding.swift:186-188`).
9. **Previews lose their demo battery.** The real `system_profiler` result overwrites `demo.battery.preview()` about 1 s later (`DataSources.swift:46-51`).

## Idle CPU and energy (the overlay runs full screen for hours)

10. **The whole overlay redraws every second, even with nothing playing** (confirmed). `NowPlaying.swift:136-140` assigns `track = new` every poll, and `@Published` fires even for nil→nil. Fix: make `Track` Equatable and assign only when it changes. Drive the 5-minute pause expiry with a one-shot timer.
11. **Night-mode modifiers always render offscreen.** `OverlayView.swift:116-120` applies `compositingGroup()` and the filters even when night mode is off. Fix: apply them only when `night.on`. The same pattern is at `SettingsStyle.swift:190`.
12. **The music backdrop runs at 60–120 fps.** `MusicMode.swift:95,123` uses `TimelineView(.animation)` with no cap, and draws the full-size cover 3× per frame. Fix: `.animation(minimumInterval: 1/30)` and downscale the artwork once in loadArtwork.
13. **The Marquee keeps animating at 60 fps through its 2.5 s hold** (`NowPlayingCard.swift:206`).
14. **The World Clock and the idle timer re-render every second** (`Widgets.swift:414,624`). The digital clock styles only need `.everyMinute`.
15. **The IdleMonitor keeps scanning every process's power assertions while the overlay is already up** (`IdleMonitor.swift:23-30`). Fix: return early when showing, and set the timer tolerance.
16. **App-lifetime timers run while the overlay is hidden.** NightMonitor (`Widgets.swift:858`) and BatteryMonitor (`DataSources.swift:28`) keep going; on a laptop, `system_profiler` runs every 2 min. Fix: start them in show() and stop them in hide().
17. **pause() keeps both 4K aerial items loaded and buffering** (`Aerials.swift:170`).
18. **A hung music player queues one AppleScript job per second.** `NowPlaying.swift:109` has no in-flight guard. Spotify artwork is fetched with a blocking `Data(contentsOf:)` on the same queue. Fix: add an isPolling flag and use URLSession for artwork.

## Robustness

19. **The "Open at login" toggle fails silently** (`Settings.swift:720`, `try? register()`).
20. **A stored `gridRows` of 0 gives NaN layout** (`OverlayView.swift:77`). Fix: validate it with `GridSize.choices`.
21. **The permission-poll Task is never cancelled, so repeat clicks stack** (`Settings.swift:699`).
22. **`tell application id` can relaunch a player that just quit** (`NowPlaying.swift:104,182`). Fix: wrap it in `if application id "…" is running`.
23. **KVC on a private blur filter** (`Glass.swift:212`) raises an uncatchable exception if macOS renames it. Fix: check that the filter exists first.
24. **The overlay can start while the display is asleep or locked** (`IdleMonitor.swift`).
25. **Work runs synchronously on the main thread:** the aerial catalog decode (`Aerials.swift:43`), EventKit `events(matching:)` (`DataSources.swift:138`), and `system_profiler` with no timeout (`DataSources.swift:57`).

## Packaging (build.sh)

26. **A missing signing identity falls back to ad-hoc silently** (`build.sh:46`, `2>/dev/null`). This resets the Calendar, Reminders, Location and Automation grants on every build. Fix: print a warning on fallback.
27. **The version is hard-coded at 0.1 (1).** Fix: read it from a `version.env`, as in the skill. Also add `LSApplicationCategoryType`.

## Swift 6 / modernisation

28. **Swift 6 language mode needs one change.** In a scratch build, `.v6` failed only at `Aerials.swift:28` (a non-Sendable static closure array); `nonisolated(unsafe)` fixes it. The test target is untested.
29. **Dead code:** `Layout.swift:199` `occupant(of:)`.
